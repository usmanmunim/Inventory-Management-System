# Inventory Management System

A console-based Inventory Management System developed in C programming language.  
This project helps manage products, categories, suppliers, stock levels, user transactions, and file-based data storage.

## Project Overview

The Inventory Management System is designed to support basic inventory operations such as adding products, updating stock, managing categories and suppliers, and recording transactions. The system uses modular programming and text file handling to store and retrieve data.

This project was developed as part of a C programming group assignment to demonstrate the use of structures, arrays, pointers, functions, and file handling.

## Features

- Add, update, delete, and view products
- Manage product categories
- Manage supplier information
- Track inventory stock levels
- Low stock checking
- Record user transactions
- Store data using text files
- Modular program structure
- Menu-driven console interface

## Technologies Used

- C Programming Language
- File Handling
- Structures
- Arrays
- Pointers
- Modular Programming
- GCC Compiler
